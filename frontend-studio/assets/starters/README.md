# Static starter

Serve the repository root and open `frontend-studio/assets/starters/static/index.html`. This is a neutral static starting point using the shared CSS roles, system-font fallbacks, and native controls. Sample content is Chinese; replace it with real content in the required language.

Copy the starter together with its relative CSS/snippet dependencies, or update paths when incorporating it into an existing app. Change theme/type scale in tokens, preserve semantic controls and labels, and verify actual longest/shortest copy before decoration. Do not treat its section order or visual appearance as a mandatory template.
