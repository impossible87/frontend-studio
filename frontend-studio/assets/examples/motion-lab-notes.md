# Motion lab: mechanisms and evidence

This original dependency-free specimen contains three fictional themes: product explanation synchronized with scroll/direct controls, studio work disclosures with spatially continuous reflow, and research tabs with interruptible content/height transitions. SVG path replay and pointer spotlight also have direct controls.

Chinese and English specimen pages share the same mechanisms. The Chinese version exercises mixed-script typography and real copy lengths. It is a mechanism lab, not a production project, a controlled AI-generation benchmark, or a required look for generated sites.

All sections share the included typography/color tokens. Static HTML remains readable before JavaScript; initialization failures restore content. Reduced motion preserves state selection with simplified transitions. Rapid switches converge on the latest selected item, tabs maintain focus behavior, and temporary layout styles are cleaned up.

Gallery browser access during the earlier development run failed. Text/documentation could inform proposed mechanisms, but no third-party gallery animation is claimed as observed. The included mechanisms were implemented and tested locally.

The public repository's validation report in `docs/validation.md` explains actual checks and their limits. Run the lab from a local HTTP server, inspect initial/middle/end, reverse/rapid interactions, keyboard, reduced motion, no JS, simulated animation initialization failure, and resize. Adapt information relationships and controls to your own content, rather than recoloring the specimen.
