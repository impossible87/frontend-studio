# Contributing

Useful contributions fix a demonstrated failure, improve a focused mechanism, or add a reproducible typography/interaction case. Keep instructions concise and preserve the user's framework and content facts.

For bugs, include the task, environment, steps, expected/actual result, and a redacted screenshot or minimal example. Remove credentials, client material, and personal data. For visual changes, include inspected before/after images with the same copy and viewport. For animation, include interruption, keyboard, reduced-motion, and fallback checks. Avoid asserting performance improvements without measurements.

Run `npm test` and `npm run check` with Node 22+. Browser checks are documented in [tools](docs/tools.md); static CI does not cover every runtime behavior. Update relevant English guidance, docs, and Chinese overview when behavior changes. Keep third-party attribution and verify the exact license before importing resources.

Open a small issue or pull request focused on the problem. No star requirement, referral reward, or promotional comments are needed to contribute.
